# LABORATORIO PRATICA
#CONTROLE DE VERSAO DE GIT E INTEGRACAO COM GITHUB
##OBJETIVOS
- VERIFICAR A INSTALACAO DO GIT NO AMBIENTE DE TRABALHO;
- CONFIGURAR NOME E EMAIL DE USUARIO NO GIT;
- CRIAR UM PROJETO SIMPLES PARA UTILIZACAO DURANTE A PRATICA;
- INICIALIZAR UM REPOSITORIO GIT;
- IDENTIFICAR O ESTADO ATUAL DE UM REPOSITORIO;
- ADICIONAR ARQUIVOS A AREA DE STAGING;
- CRIAR COMMITS COM MENSAGENS DESCRITIVAS;
- CONSULTAR HISTÓRICO DE COMMITS;
- MODIFICAR ARQUIVOS E REGISTRAR NOVAS VERSOES DO PROJETO;
- CRIAR E PUBLICAR UM REPOSITORIO NO GITHUB;
